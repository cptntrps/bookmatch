## Behavioral contracts

**Corpus and index**
- **index is built only from explicit ratings** — `scripts/build_index.py` keeps interactions with `rating > 0`; the source describes the rating domain as 1..5, but the filter enforces no upper bound.
- **index rebuild is idempotent** — `scripts/build_index.py` rewrites the index directory each run.
- **one normalization on both sides** — `bookmatch/match.py` `normkey` is called by `scripts/build_index.py` and at query time, so the lossy title/author joint is consistent.
- **corpus loads once per process** — `bookmatch/corpus.py` `Corpus` loads lazily and holds the index for the process lifetime; `bookmatch/app.py` instantiates one `Corpus` at lifespan startup.

**Analysis and agent**
- **geometry stays pure** — `bookmatch/analyze.py` takes a pre-computed embedding matrix; `bookmatch/embed.py` owns the embedding calls, so the math is unit-testable without Ollama.
- **embeddings sent raw** — `bookmatch/embed.py` sends texts with no prefix and no lowercasing, so vectors stored by earlier versions stay comparable.
- **agent is grounded two ways** — `bookmatch/agent.py` puts the taste profile and neighbor-gap recommendations in the system prompt and exposes one live tool, `project_axis`.
- **verdicts outlive re-analysis** — `bookmatch/verdicts.py` stores verdicts in their own table and applies them to the shelf at analysis time via `merge_into_shelf`.

**Persistence**
- **additive schema** — explicit migration-time bootstrap `python -m bookmatch.storage` creates schema and tables with `IF NOT EXISTS`; app startup only verifies presence; embeddings are stored as raw float32 bytes, not pgvector.

**Deploy**
- **fail-loud deploy** — `deploy.sh` aborts non-zero on a missing sudo ticket, a failed restart, or a dead `/api/health`.
- **health gate** — `/api/health` must return `ok:true` AND `corpus_ready:true`; a 200 with `corpus_ready:false` is unhealthy and `deploy.sh` attempts rollback to the recorded `.deploy-last-good`; rollback may fail or lack a target, and the deploy exits nonzero.
- **secrets drop-in is mandatory** — the unit asserts `/etc/systemd/system/bookmatch.service.d/sops.conf` exists and refuses to start without it.
- **test gate on push** — `scripts/install_hooks.sh` points `hooksPath` at the committed `.githooks/`; a fresh clone that skips it has pushes that silently bypass the ADR-0020 test gate.
