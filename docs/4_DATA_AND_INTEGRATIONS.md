## Env keys

**connection**

- `BOOKMATCH_RAW` — raw data directory for the UCSD Goodreads corpus, defaulting to `~/data/goodreads-ucsd/raw`.
- `BOOKMATCH_INDEX` — output directory for the built index, defaulting to `~/data/goodreads-ucsd/index`.

**application credentials and model configuration**

- `BOOKMATCH_PG_DSN` or fallback `PG_DSN` — Postgres connection (`bookmatch/storage.py`).
- `BOOKMATCH_CHAT_URL`, `BOOKMATCH_CHAT_KEY`, `BOOKMATCH_CHAT_MODEL` — chat endpoint, bearer key and model (`bookmatch/agent.py`).
- `BOOKMATCH_GATEWAY_URL`, `BOOKMATCH_GATEWAY_KEY` — production gateway fallbacks; `OPENAI_API_KEY` is the final chat key fallback.
- `BOOKMATCH_EMBED_URL`, `BOOKMATCH_EMBED_KEY`, `BOOKMATCH_EMBED_MODEL` — embedding endpoint, bearer key and model (`bookmatch/embed.py`).

The download/deploy names `BASE`, `BRANCH`, `DEST`, `FILES`, `LAST_GOOD_FILE`, `PREV` and `TARGET` are shell-local variables, not environment configuration for the application. Credential storage, delivery and rotation are documented in Quality.
